## 🎨 视觉与体验

以苹果式中性底和少量青色强调为核心，提供浅色、深色与系统跟随，并支持青蓝、青碧、靛紫、青绿四套强调色在设置中切换。界面保持极简、稳定、克制，适合长期使用。

---

## ✨ 核心特性

- **极简美学**: 中性背景 + 可选强调色，界面更接近 Codex/ChatGPT 的克制风格。
- **Pi Harness 内核**: 采用 Pi 框架，拥有广泛的 Model Provider 兼容性，以及轻量、高效的 Agent 执行引擎。
- **内置 Alpine 虚拟机**: 自动安装 Alpine Linux 运行环境，开箱即用，支持各种 Linux 工具与命令行操作。
- **扩展主机控制**: 支持可选的 Shizuku 与 Termux 扩展，用于直接操纵和控制手机系统。
- **Extensions**: 兼容 Pi Extensions，可对 UI 和应用逻辑进行高度自由地更改。
- **PC Codex 联动**: 支持向桌面 Codex 下发任务、查看进度并同步会话历史。
